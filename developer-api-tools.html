Flutter 与 Android Studio SDK 下载慢：镜像、代理与离线的处理

先分清是哪一步慢

移动开发要下载的东西很多：Flutter SDK、Android SDK、构建工具、模拟器镜像和各种依赖库。先看卡在哪一步，才好对症处理。

Flutter 的镜像设置

通过设置环境变量，让 Flutter 从镜像站下载引擎与依赖包。设置后重新打开终端，再运行诊断命令确认环境。镜像站要选择更新及时、来源可信的。

Android Studio 的代理

在设置的 HTTP 代理页面填写代理地址和端口，使用检查连接功能确认可用。SDK 管理器、Gradle 同步和插件市场都会读取这里的设置。

离线与缓存

  • 体积很大的系统镜像可以在网络好时先下载保存。
  • 构建缓存损坏时，清理后重新同步。
  • 在团队里共享已下载的 SDK 压缩包，省去重复下载。

小结

镜像加速度、代理保稳定、离线做兜底，三者搭配，环境搭建不再是噩梦。
